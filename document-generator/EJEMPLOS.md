## Ejemplo 5: Crear un Informe

### Datos de ejemplo:
```
Número: 012-2026-TI
Destinatario: Gerente General
Cargo Destinatario: Gerencia General
Remitente: Luis Torres
Cargo Remitente: Jefe de Tecnología
Asunto: Informe de incidentes de seguridad - Marzo 2026

Antecedentes:
Durante el mes de marzo de 2026 se registraron 3 intentos de acceso no autorizado a los sistemas de la empresa. El equipo de seguridad implementó medidas preventivas inmediatas.

Análisis:
Los intentos de acceso provinieron de direcciones IP extranjeras y se dirigieron específicamente al servidor de base de datos. El firewall bloqueó exitosamente todos los intentos. Sin embargo, se detectaron vulnerabilidades en el sistema de autenticación que podrían ser explotadas.

Conclusiones:
1. El sistema de seguridad actual funcionó correctamente
2. Existen vulnerabilidades que deben ser corregidas
3. Se requiere actualización de protocolos de seguridad

Recomendaciones:
1. Implementar autenticación de dos factores
2. Actualizar el sistema de firewall
3. Realizar auditoría de seguridad trimestral
4. Capacitar al personal en ciberseguridad
```

## 💡 Consejos de uso

### Para Solicitudes:
- Sé claro y conciso en el motivo
- Proporciona todos los detalles necesarios
- Mantén un tono formal y respetuoso

### Para Memorandos:
- Usa numeración correlativa
- Sé directo en el asunto
- Incluye solo información relevante

### Para Informes:
- Estructura la información en secciones claras
- Usa viñetas para listas
- Incluye datos concretos y fechas

### Para Cartas:
- Personaliza el saludo
- Mantén un tono profesional pero cercano
- Cierra con una despedida apropiada

### Para CV:
- Usa viñetas para facilitar la lectura
- Destaca logros específicos
- Mantén la información actualizada
- Sé honesto con tus habilidades

## 🎯 Flujo de trabajo recomendado

1. **Selecciona** el tipo de documento
2. **Completa** todos los campos del formulario
3. **Revisa** la vista previa en tiempo real
4. **Ajusta** cualquier información si es necesario
5. **Guarda** el documento en la base de datos
6. **Descarga** el PDF cuando esté listo

## 📝 Notas importantes

- La fecha se genera automáticamente
- Puedes editar documentos guardados
- Los documentos se guardan en tu cuenta personal
- Solo tú puedes ver tus documentos
- Puedes descargar PDF sin guardar el documento
